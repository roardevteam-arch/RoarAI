Roblox Studio Plugin

To use ROAR in Roblox Studio:

  1. Download RobloxAIPlugin.lua from the GitHub repo
  2. Open Roblox Studio → Plugins → Open Plugin Folder
  3. Place the file there and restart Studio
  4. Click the ROAR plugin button in the Plugins tab
  5. Select code in the Explorer and click "Analyze with ROAR"

The plugin sends your selected code to ROAR for AI-powered analysis and suggestions.
