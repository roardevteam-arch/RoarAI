# Contributing to ROAR AI

We love contributions! Here's how to help:

## Getting Started

1. Fork the repository
2. Clone your fork: `git clone https://github.com/yourusername/RoarAI.git`
3. Create a branch: `git checkout -b feature/my-feature`
4. Install dependencies: `cd server && npm install`
5. Start development: `NODE_ENV=development npm start`

## Development Guidelines

- Use meaningful commit messages
- Test your changes locally
- Update README if adding features
- Follow existing code style
- Keep it simple and maintainable

## Bug Reports

- Check existing issues first
- Describe the problem clearly
- Include steps to reproduce
- Mention your OS and Node.js version

## Feature Requests

- Describe the feature and why it's useful
- Give examples of how it would work
- Consider backward compatibility

## Code Review

All PRs are reviewed for:
- Code quality
- Security
- Performance
- Documentation
